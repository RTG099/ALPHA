Quick Install Guide

  1. Windows: Download ALPHA-Setup-*.exe and run it. If Windows SmartScreen appears for a new unsigned release, click More info → Run anyway.
  2. Android: Download ALPHA-Android-*.apk on your phone and tap it. Allow installing from your browser/file manager once when prompted by Android.
  3. Future Updates: Open Settings → Updates inside ALPHA anytime to check for and install newer versions automatically.
