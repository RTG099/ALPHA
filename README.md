# ALPHA Media Player

Official home for **ALPHA Media Player** on **Windows** and **Android**, created by **RTG099**.

- **Official Download Website:** https://rtg099.github.io/ALPHA/
- **All Releases (`.exe` & `.apk`):** https://github.com/RTG099/ALPHA/releases

## Platforms
- **Windows (64-bit):** `ALPHA-Setup-*.exe`
- **Android (8.0+):** `ALPHA-Android-*.apk`

Both apps include a built-in **Settings → Updates** checker that automatically reads the latest release from this repository.
